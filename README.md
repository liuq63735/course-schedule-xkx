# 校科协智能课表管理

基于 **Python Flask + SQLite + HTML/CSS/JavaScript（Bootstrap 5）** 开发的校科协智能课表管理，
用于学生组织（社团）内部录入并共享成员课表、开展"谁这段时间没课"的空闲查询。

---

## 一、快速运行

```bash
# 1. 安装依赖（Python 3.9+，Windows 上若 `python` 不可用请改用 `py`）
py -m pip install -r requirements.txt


# 2. 启动（首次运行会自动在项目目录创建 schedule.db 数据库）
py app.py

# 3. 浏览器打开
#    http://127.0.0.1:5000
```

> - 若要让宿舍/团队内其他电脑访问，把 `app.py` 最后一行改为
>   `app.run(host="0.0.0.0", port=5000, debug=True)`，其他电脑访问
>   `http://你的IP:5000`，并放行防火墙。
> - 正式部署建议不要开启 `debug=True`，并设置环境变量 `SECRET_KEY`。

**第一次使用**：**第一个注册的用户会自动成为管理员（admin）**，请由组织负责人先注册，
然后在"管理后台 → 学期管理"中创建并激活当前学期，成员即可开始录课。

## 二、主要功能

### 1. 用户与权限
- 注册字段：学号、密码、真实姓名、专业、性别、手机号、身份（主席/部长/副部长/干事）、部门（六个部门下拉）。
- **主席不需要选择部门**（注册时部门框自动禁用）。
- **届数自动分配**：注册年份即届数，如 2026 年注册为 `2026届`（管理员可在"用户管理"中修改）。
- 角色两类：`管理员 admin` / `普通成员 member`：
  - 第一个注册用户自动为管理员；
  - 管理员可管理全部数据，并可在"用户管理"里提升/降级他人、编辑成员信息、删除用户；
  - 普通成员只能编辑**自己**的课表，只能查看他人课表。
- 支持修改登录密码。
- “设置”页面可修改专业，也可修改登录密码。
- 管理员用户管理页会显示性别、手机号，并按部门统计成员数量。

### 2. 学期管理（管理员）
- 新建学期：名称（如 `2026-2027-1`）、**开始日期（应为第 1 周的周一）**、总周数。
- 每个学期可被设为"当前学期"；**普通成员只能在当前学期录入课程**。
- 首个创建的学期自动成为当前学期；当前学期不可直接删除（需先激活其他学期）。
- 系统会根据学期开始日期与当前系统日期**自动计算"当前周"**。

### 3. 节次与时段
- 周一至周五按 12 节划分：
  1-4 节 **上午**、5-8 节 **下午**、9-12 节 **晚上**。
  | 节次 | 时间 | | 节次 | 时间 | | 节次 | 时间 |
  |---|---|---|---|---|---|---|---|
  | 1 | 08:00-08:45 | | 5 | 13:30-14:15 | | 9 | 18:30-19:15 |
  | 2 | 08:55-09:40 | | 6 | 14:25-15:10 | | 10 | 19:25-20:10 |
  | 3 | 09:55-10:40 | | 7 | 15:25-16:10 | | 11 | 20:20-21:05 |
  | 4 | 10:50-11:35 | | 8 | 16:20-17:05 | | 12 | 21:15-22:00 |
- **周六、周日不按节划分**，分为 上午 / 中午 / 晚上 三个时段，**自由填写要做的事情**；
  展示时与工作日同一张 12 节矩阵，其中 上午≈第1-4节、中午≈第5-8节、晚上≈第9-12节。

### 4. 课程 / 周末事项录入
- 成员登录后为**当前学期**添加内容，支持两类：
  - 工作日课程：课程名称 + 星期(周一~周五) + 开始节次~结束节次 + 周次范围；
  - 周末事项：要做的事情 + 周六/周日 + 时段(上午/中午/晚上)。
- **周次范围**：起始周、结束周，并选择 **全周 / 单周(奇) / 双周(偶)**，
  例如"第 2-16 周单周"只在第 3、5、7…周出现。
- 录入/编辑/删除：本人或管理员对目标成员课表操作。

### 5. 课表展示
- 任何登录成员可查看**任意成员**的课表；默认打开自己的课表并显示**当前周**。
- 顶部工具栏：切换学期、上一周/下一周/回到当前周、按**部门 + 成员关键词**筛选；成员关键词支持姓名、学号和专业。
- **周一~周日合并为同一张 12 节矩阵**展示（自动处理同一时间重叠内容的并排布局）：
  周一~周五按节次；周六/周日按 上午=1-4 / 中午=5-8 / 晚上=9-12 呈现自定义安排。
  当天列高亮，支持打印。

### 6. 管理员后台
- 概览：成员数、学期数、课程数、当前学期。
- 用户管理：查看所有成员，设/撤管理员，编辑身份/部门/届数，删除用户（连带其课表）。
- 学期管理：增删改、设当前学期。
- **空闲查询**：选择 学期 + 周数 + 星期 + 节次范围（或周末时段），
  再按 **部门、届数** 过滤，即可列出**该时段没有课**的同学名单（含空闲人数统计），
  并可直接跳转到其该周课表查看核对。

## 三、数据表结构（SQLite）

数据库文件：项目目录下 `schedule.db`，首次启动自动创建。

- **users 用户表**：学号(唯一)、密码哈希、姓名、身份、部门、届数、角色、注册时间。
- **semesters 学期表**：名称、开始日期、总周数、是否当前学期。
- **courses 课程表**（含工作日课程与周末事项两类记录）：
  所属用户、所属学期、内容名称、星期(1-7)、开始/结束节次(工作日)、
  周末时段(morning/noon/evening，周末)、起始/结束周、周次类型(all/odd/even)。

删除用户/学期时，其课程记录会级联删除。

```
course_schedule_system/
├── app.py                 # Flask 主程序（路由 / 业务 / 建表）
├── requirements.txt       # 依赖：Flask、Werkzeug

    ├── login.html               # 登录
    ├── register.html            # 注册
    ├── settings.html            # 个人设置（专业 / 修改密码）
    ├── schedule.html            # 课表总览 + 管理
    ├── item_form.html           # 添加 / 编辑课程与周末事项
    └── admin/
        ├── dashboard.html       # 后台概览
        ├── users.html           # 用户管理

        ├── semesters.html       # 学期管理
        ├── semester_edit.html   # 编辑学期
        └── free.html            # 空闲查询
```

## 五、常用说明与约定

1. 密码使用 Werkzeug 加盐哈希存储（不保存明文）。
2. "第 X 周"以学期 `开始日期`（周一）为第 1 周起点推算；若今天早于开学则回落到第 1 周。
3. 系统需至少保留一名管理员（不能降级/删除最后一名管理员）。
4. 主席（身份）与管理员（角色）是两个概念：主席可被授权为管理员，
   也可只是普通成员；一般由管理员在"用户管理"中调整。
5. 若改了学期总周数/开始日期，会立即影响该学期的"当前周"计算。
